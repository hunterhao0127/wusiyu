# 务思语 v1.6.1 网页批注实施计划

1. 新增共享批注核心和单元测试：固定新建、修改、删除、定位、排序与 Markdown 规则。
2. 扩展共享记录类型和备份测试：确保批注进入 v2 JSON/ZIP，墓碑可合并，API Key 仍被拒绝。
3. 实现共享批注 UI 模块：工具条、四色编辑器、批注列表和 Markdown 下载。
4. 在 Web 入口做最小接入：把 DOM Range 转成内容块偏移，在每次渲染后恢复高亮，复用现有 IndexedDB 记录写入链。
5. 运行全部共享测试、共享资产一致性检查和静态脚本语法检查。
6. 启动本机 Web，用真实 EPUB 验证创建、刷新、修改、删除、跳转、阅读模式切换、Markdown 和备份恢复，再交给用户试用。

本计划不修改 Desktop 页面、Mac/Windows 版本号、安装包或 GitHub 线上内容。
