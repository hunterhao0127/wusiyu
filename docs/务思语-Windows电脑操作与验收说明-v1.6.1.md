# 务思语 Windows 电脑操作与验收说明（v1.6.1）

这份说明只用于 Windows 真机验收。云端已经完成源码检查、Windows 后端冒烟检查和 NSIS 安装包构建；以下项目必须在 Windows 电脑上实际操作，不能由 Mac 代替。

## 1. 下载前确认

1. 打开 GitHub Release：<https://github.com/hunterhao0127/wusiyu/releases/latest>。
2. 下载 `wusiyu-1.6.1-windows-x64-setup.exe`（若 Release 的最终文件名略有不同，以 `.exe` 结尾的 Windows 安装包为准）。
3. 不要从聊天软件转发包或第三方网站下载。

可选：在 PowerShell 验证下载文件的 SHA-256。将路径替换成实际文件名：

```powershell
Get-FileHash "$HOME\Downloads\wusiyu-1.6.1-windows-x64-setup.exe" -Algorithm SHA256
```

Release 页会同时给出对应的 SHA-256；两者必须一致。

## 2. 首次安装

1. 双击安装包，选择“自定义安装”。
2. 保持“创建桌面快捷方式”和“创建开始菜单快捷方式”勾选。
3. 可以选择中文路径，例如 `D:\学习软件\务思语`。
4. 安装完成后从桌面快捷方式启动。
5. 确认程序只有一个主窗口，没有额外黑色命令行窗口。

如果 Defender 或 SmartScreen 有提示：先确认文件来自上面的 GitHub Release、校验和一致，再选择“更多信息 → 仍要运行”。不要关闭 Defender，也不要从未知来源重新下载。

## 3. 基础启动与数据目录

启动后逐项确认：

- 书库、设置、单词本、复习和批注入口均可打开。
- 关闭再启动后，已导入书籍、阅读位置、单词本和批注仍保留。
- 在设置中配置一个可用 AI 后，查词或翻译能得到真实响应。
- 程序数据保存在 Windows 用户数据目录中；卸载前先导出学习数据，不要手工删除用户数据目录。

## 4. 从旧版覆盖升级

若电脑已安装旧版务思语，先执行下面的准备，再直接安装 v1.6.1；**不要先卸载旧版**：

1. 旧版导入一本小书或确认已有书籍。
2. 加入一个单词，翻到非首页。
3. 选择一段文字，建立一条带笔记的批注。
4. 通过设置中的“导出学习数据”另外保存一份备份。
5. 直接运行 v1.6.1 安装包，覆盖同一安装目录。
6. 启动新版后确认书籍、单词、阅读位置、批注和设置都保留。

若数据没有保留，立即停止反复安装；保留导出的备份和错误截图，再反馈问题。

## 5. v1.6.1 批注验收

打开一本书，按顺序测试：

1. 选中 1–500 个字符，工具条应显示翻译、高亮/笔记、加入单词本等操作。
2. 新建黄、绿、蓝、粉四种颜色的高亮，至少一条填写笔记。
3. 单击已高亮的单词，确认仍可查词。
4. 双击已高亮文字，确认能打开原笔记并可修改、换色或删除。
5. 再次选中同一段文字，确认显示“查看笔记”或“添加笔记”，不会创建重叠重复批注。
6. 打开“批注”面板，分别测试“全部”“有笔记”、跳回原文和 Markdown 导出。
7. 关闭并重开程序，确认批注仍存在。

## 6. Mac、Web、Windows 互相导入

准备一个由 Mac 或网页版导出的 v1.6.1 JSON/ZIP 备份；如需要连书一起迁移，导出时勾选“包含所选书籍”。

1. Windows 设置中选择“导入学习数据”，选择备份文件。
2. 确认单词本、阅读位置、阅读设置和批注都恢复。
3. 若 ZIP 含书籍，确认书库出现该书，打开后批注能定位到原文。
4. 在 Windows 新增或修改一条批注后导出，再分别在 Mac 和网页端导入验证。
5. 删除一条批注后导出、再导入旧备份；已删除的批注不能被旧备份重新恢复。

导出文件不应包含 API Key。请只在自己设备间传输备份，不要公开上传。

## 7. 更新提示与当前更新方式

当前 v1.6.1 已实现“检测新版本 → 显示说明 → 打开官方 Release 下载页”。验证方法：以后发布比当前版本更高的 Release 后，重新启动程序，确认它出现“发现务思语新版本”提示，点击“立即下载”只能打开 `github.com/hunterhao0127/wusiyu` 的 Release 页面。

**当前不是静默自动替换安装包。** 用户仍需要从官方 Release 下载新版 `.exe` 并覆盖安装，学习数据会保留。这样做是当前最稳妥的发布方式，直到 Windows 签名、升级包校验和回滚策略都完成真实验证。

## 8. 卸载验收

1. 在“设置 → 应用 → 已安装的应用”中卸载务思语。
2. 确认开始菜单和桌面快捷方式消失。
3. 重新安装后，根据产品的数据保留策略确认用户数据是否仍在；卸载前导出的备份应始终可重新导入。

## 9. 反馈时请附带

- Windows 版本和系统架构。
- 安装包完整文件名及 SHA-256。
- 问题发生步骤、截图和准确报错文字。
- 是否为旧版覆盖升级、是否使用中文安装路径。
- 是否能从 Mac/Web 备份恢复、AI 供应商名称（不要发送 API Key）。
